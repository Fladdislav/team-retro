# 🚀 Team Retro — Веб-инструмент для проведения ретроспектив

Современный, интерактивный веб-сервис для проведения командных ретроспектив в реальном времени. Разработан для Agile / Scrum / Kanban команд, фасилитаторов и тимлидов.

---

## ✨ Ключевые возможности

### 1. 🔄 Совместная работа в реальном времени (WebSockets)
- Мгновенная синхронизация без перезагрузки страницы (добавление, редактирование, перемещение карточек, реакций и голосов).
- Аватары участников онлайн со статусом активности.
- Ссылка на комнату в 1 клик для всей команды (`/retro/:roomId`).

### 2. 📋 6 готовых шаблонов ретроспектив + свои колонки
- **Классическое (Went Well / Improve / Ideas)**: Что было хорошо, Что пошло не так, Что улучшить, Благодарности.
- **Mad / Sad / Glad**: Бесит 😡, Грустно 😢, Радует 😊 (эмоциональное ретро).
- **Start / Stop / Continue**: Начать делать 🚀, Прекратить 🛑, Продолжить 🔄.
- **4L**: Liked ❤️, Learned 💡, Lacked 🧩, Longed for 🌟.
- **Парусник (Sailboat)**: Попутный ветер ⛵, Якоря ⚓, Рифы 🪨, Остров мечты 🏝️.
- **DAKI**: Drop 🗑️, Add ➕, Keep 📌, Improve 🛠️.
- **Кастомные колонки**: Возможность добавлять любые свои колонки прямо во время встречи.

### 3. 🎯 6 фаз управляемого сценария встречи (Facilitator Stepper)
1. **🌡️ Пульс команды (Ледокол / Icebreaker)**: Быстрый опрос настроения (1–5 с эмодзи от 🌪️ Хаос до 🚀 Огонь) с моментальным подсчетом среднего балла команды.
2. **💡 Сбор идей (Brainstorming)**: Индивидуальная генерация мыслей. Поддерживается **приватный режим "Скрыть карточки" (Blur Mode)**, чтобы участники не списывали и не влияли на мнение друг друга до открытия!
3. **🗂️ Группировка (Group & Merge)**: Drag-and-drop карточек между колонками или объединение нескольких похожих карточек в общую тему.
4. **🗳️ Точечное голосование (Dot Voting)**: Настраиваемый лимит голосов на участника (3, 5, 8). Сортировка карточек по числу голосов.
5. **✅ План действий (Action Items)**: Назначение конкретных договоренностей, ответственных (@ник) и дедлайнов.
6. **📊 Итоги и экспорт**: Сводка встречи, экспорт в Markdown, Jira / Confluence, CSV и запуск праздничного конфетти 🎉.

### 4. ⏱️ Синхронный таймер со звуком
- Общий таймер для всех участников с точностью до секунды.
- Звуковые сигналы (программный синтез через Web Audio API — без внешних аудиофайлов).
- Предупреждающая анимация за 30 секунд до конца фазы.
- Удобное добавление времени (`+1м`) и горячая клавиша `Пробел` для паузы/старта.

### 5. 🎨 Продуманный UX и дизайн
- Темная и светлая тема оформления.
- Теги для категоризации (Процессы, Команда, Техдолг, Инструменты, QA, Продукт).
- Эмодзи-реакции (👍, ❤️, 🚀, 💡, 🔥, 👏, 🎯, 👀).
- Возможность писать анонимно (🎭).
- Canvas-анимация конфетти для всей команды.
- Локальное сохранение состояния комнат в JSON (данные сохраняются при перезагрузке сервера).

## 🚀 Быстрый старт

### Требования
- Node.js 18+ (проверено на Node.js v26)
- npm

### Установка и запуск

1. Перейдите в папку проекта:
```bash
cd team-retro
```

2. Установите зависимости (требуются только Express и Socket.IO):
```bash
npm install
```

3. Запустите сервер:
```bash
npm start
```
*(Или в режиме разработки с автоперезагрузкой: `npm run dev`)*

4. Откройте в браузере:
👉 **[http://localhost:3000](http://localhost:3000)**

## 👥 Как использовать в команде

### Вариант 1: В локальной сети (Wi-Fi / VPN)
Узнайте свой локальный IP (например, `ifconfig` на Mac или `ipconfig` на Windows) и отправьте коллегам ссылку:
`http://192.168.1.XX:3000`

### Вариант 2: Через туннель (ngrok / localtunnel)
```bash
npx localtunnel --port 3000
```
Или с ngrok:
```bash
ngrok http 3000
```

### Вариант 3: Деплой на бесплатный хостинг (Render, Railway, Fly.io)
Проект не требует внешних баз данных и готов к деплою одной командой `npm start`.

## 🛠️ API & Экспорт

- `GET /api/templates` — список доступных шаблонов и этапов.
- `GET /api/rooms` — список существующих комнат с метаданными.
- `POST /api/rooms` — создание новой комнаты: `{ title, template, votesPerUser }`.
- `GET /api/rooms/:id/export/markdown` — скачать итоги в формате `.md`.
- `GET /api/rooms/:id/export/csv` — скачать карточки и задачи в формате `.csv` (с UTF-8 BOM для Microsoft Excel).
- `GET /api/rooms/:id/export/json` — полная выгрузка данных комнаты.

## 🧪 Тестирование

Для запуска сквозного теста взаимодействия двух клиентов в реальном времени:
```bash
node test-retro.js
```
Тест симулирует подключение Алисы и Боба, прохождение опроса настроения, добавление карточек, голосование, фиксацию задач и проверку экспорта.
